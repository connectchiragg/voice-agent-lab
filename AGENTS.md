# Learning workflow

- The owner is learning to read, write, trace, and debug code independently.
- Explain one small step at a time. Let the owner implement the core WebSocket,
  conversation-state, and LLM-streaming logic unless explicitly asked to write it.
- Offer hints before complete solutions. Do not fill every TODO automatically.
- Prefer explicit control flow, small functions, and minimal dependencies.
- Keep transport separate from conversation logic as that logic is introduced.
- Do not add frameworks, infrastructure, or later milestones without agreement.
- Test each completed increment and state what is intentionally incomplete.
- Never commit API keys, recordings, or private conversation data.
